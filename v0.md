# v0 — Daily-Driver Cogmo

Minimum feature set to use cogmo every day. Phase 1 complete + usable.

## Infrastructure

- [x] `p1` Streaming responses — unified `DeliveryRouter`, `StreamingAdapter`/`StreamHandle`, `TelegramStreamHandle`; see `design/transport/streaming.md`
- [x] `p1` Session lifecycle — Inngest idle timer (cancelOn inbound), resolveSession staleness safety net, conversation/idle event, `/new` command
- [x] `p1` Context window management — `countTokens()` on LlmProvider, model registry, three-layer compaction pipeline (clear tool results → summarize → truncate), usage tracking; see `design/context-management.md`
- [x] `p2` Typed LLM calls — `chatTyped()` with Zod schemas, `responseFormat`, retry with feedback injection
- [x] `p2` Debounce wiring — debounce-router, debounce-idle, debounce-maxwait; handle-message triggers on `inbound/ready`; entry guards (staleness, await_input); resume policy
- [x] `p2` Crash recovery — Inngest durable steps, automatic resume; summarization LLM call wrapped in `step.run`, replay test via `@inngest/test`, see `design/crash-recovery.md`
- [x] `p2` Response routing — source routing per `design/transport/response-routing.md`; DeliveryRouter resolves targets via inbound message cursor chain
- [x] `p3` Telegram response formatting — `marked` + custom HTML post-processor, `renderOutput` on AdapterModule, `steering_rules.channel_type` scope, seeded Telegram rules

## LLM Provider

- [x] `p1` `chatStream()` — `ChatStreamResult` on `LlmProvider`; Anthropic adapter with tool input accumulation
- [x] `p1` `ImageBlock` — canonical type + both provider adapters + Telegram photo handler + S3 storage via Transport.uploadAttachment
- [x] `p1` Prompt caching — Anthropic: cache_control on system + last tool; OpenRouter: passthrough via promptCaching config; OpenAI/xAI: automatic
- [x] `p1` OpenAI-compatible adapter — `OpenAICompatibleProvider` using OpenAI SDK, covers OpenAI/xAI/OpenRouter/any compat endpoint
- [x] `p2` `Usage.cacheReadTokens` / `cacheCreationTokens` — reported by Anthropic adapter
- [x] `p2` `responseFormat` on `ChatParams` — JSON Schema structured output; Anthropic tool_use trick, OpenAI native
- [x] `p2` `ThinkingBlock` + thinking config on `ChatParams` — extended thinking with `clearOldThinking` pre-pass
- [x] `p3` `countTokens()` — required method on `LlmProvider`; Anthropic native API, OpenAI via js-tiktoken
