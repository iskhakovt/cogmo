# v0 — Daily-Driver Personal Assistant

Minimum feature set to use the assistant every day. Phase 1 complete + usable.

## Infrastructure

- [x] `p1` Streaming responses — unified `DeliveryRouter`, `StreamingAdapter`/`StreamHandle`, `TelegramStreamHandle`; see `design/transport/streaming.md`
- [ ] `p1` Session lifecycle — idle detection (~5 min), `/new` command
- [ ] `p1` Context window management — token counting, truncate oldest at ~80%
- [ ] `p2` Typed LLM calls — Zod schemas + retry with feedback injection
- [ ] `p2` Debounce wiring — implement debounce-router, debounce-idle, debounce-maxwait per `design/transport/debounce.md`; switch handle-message trigger from `inbound/arrived` to `inbound/ready`
- [ ] `p2` Crash recovery — Inngest durable steps, automatic resume
- [ ] `p2` Response routing — source routing per `design/transport/response-routing.md`; current impl returns all sessions, design traces inbound → session
- [ ] `p3` Telegram response formatting — HTML or MarkdownV2

## LLM Provider

- [x] `p1` `chatStream()` — `ChatStreamResult` on `LlmProvider`; Anthropic adapter with tool input accumulation
- [ ] `p1` `ImageBlock` — `{type: "image", source: "base64"|"url", data, mediaType}` in `ContentBlock`; Telegram users paste images
- [ ] `p1` Prompt caching — optional `cacheControl` hints on `ChatParams`; Anthropic explicit, OpenAI/xAI automatic (no-op)
- [x] `p1` OpenAI-compatible adapter — `OpenAICompatibleProvider` using OpenAI SDK, covers OpenAI/xAI/OpenRouter/any compat endpoint
- [ ] `p2` `Usage.cacheReadTokens` / `cacheCreationTokens` — track actual costs with caching
- [ ] `p2` `responseFormat` on `ChatParams` — JSON Schema for structured output (Zod → guaranteed output)
- [ ] `p2` `ThinkingBlock` + thinking config on `ChatParams` — extended thinking, currently silently dropped
- [ ] `p3` `countTokens()` — optional method on `LlmProvider`; only Anthropic/OpenAI/Google support it
