`tsc` now type-checks every `.test.ts` file in the project. The previous `tsconfig.json` excluded test files, so type drift in fixtures, mock factories, and assertion helpers only surfaced at runtime — and only on the integration tier. About 300 pre-existing errors were fixed up: missing fields on `Profile` / `CodingRepoRow` / `CodingTaskRow` test fixtures (`voiceMode`, `identityName`, `verifyTimeoutSeconds`, `prMetadata`, `conversationId`), partial-mock casts replaced with `mock<T>()` from `vitest-mock-extended`, JSON.parse `unknown` results funnelled through Zod schemas, narrowing helpers (`expectDefined`, `assertKind` in `src/test/assertions.ts`) instead of `!` non-null assertions, deep-merging Transport sub-namespace overrides via `mockTransportDeep` in `src/test/factories.ts`, and explicit checks for `noUncheckedIndexedAccess` array/map accesses. Net effect: a typo in a test fixture now fails `pnpm typecheck` locally instead of waiting for CI.

While at it, also pruned 19 of 29 lint suppressions: 11 dockerode `as any` casts in `supervisor.test.ts` collapsed into one `as unknown as Docker` boundary inside `fakeDocker`; 7 `as any` factory-dispatch stubs in `sandbox/factory.test.ts` switched to `mock<T>()`; 18 daytona test casts (`as unknown as ReturnType<typeof vi.fn>`) replaced with `vi.mocked(...)` to recover the Mock interface; two `// useYield` generator stubs rewritten as hand-rolled `AsyncIterable`s whose `next()` throws; two `// noNonNullAssertion`s eliminated by capturing the narrowed value as a `const` before the closure (`orchestrator.ts`) and by extracting `mutatedHost` / `mutatedLabels` as locals before assembling `mutated` (`policy.ts`); the orchestrator's `BackendUsage` field stopped being `any` (the type is exported, the comment was wrong). The remaining 10 are real framework limitations (Inngest function/event type variance, Drizzle `pushSchema(PgDatabase<any>)`, an `@ts-expect-error` for an intentionally invalid Zod input, and the `Function` leaf in `DeepPartial`). CLAUDE.md gained three new test-typing patterns documenting the `mock<T>()` Proxy gotcha for absent optional namespaces, the `expectDefined` / `assertKind` helpers, and `mockTransportDeep`.
