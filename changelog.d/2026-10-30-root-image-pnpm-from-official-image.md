**The runtime image takes pnpm from `ghcr.io/pnpm/pnpm`**, as devbase does, so it can move to a Node image that ships no corepack (25 and later). Bake's `PNPM_VERSION` and `PNPM_DIGEST` pin it, and the install fails unless pnpm's version matches `packageManager`. The root `Dockerfile` keeps defaults for both so a plain `docker build` works; `docker-bake.integration.test.ts` holds them to bake's values.
