Tightens the skills deps configuration story on two axes. (1) The register-time lockfile-compile sandbox now mounts the same shared `/skill-venvs` volume as the populator and exports `UV_CACHE_DIR=/skill-venvs/.uv-cache`, so wheel metadata fetched during compile is reused by every subsequent populate -- repeated registers no longer re-fetch from PyPI from scratch. (2) `COGMO_SKILLS_DEPS_VOLUME` is now required (no default). A shared default name would cross-mount every Cogmo instance on the same Docker host or Daytona org into one cache, making a compromised skill in one deployment a poisoning vector for the others; operators now pick a name explicitly per deployment (e.g. `cogmo-skills-deps-cache` single-tenant, `cogmo-skills-deps-cache-staging` / `...-prod` for shared infra).
