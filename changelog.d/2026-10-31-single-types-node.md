**The dependency tree holds one `@types/node`.** `@types/ssh2`, through dockerode's and testcontainers' types, was the only package asking for `@types/node` 18, and with that second copy present Dependabot's re-resolution rebound every package that accepts any version (`@types/pg`, `@types/connect` and others under Inngest's instrumentations) to 18. An override in `pnpm-workspace.yaml` gives `@types/ssh2` the 26 copy, and `engine-ranges.test.ts` fails if a second version appears.
