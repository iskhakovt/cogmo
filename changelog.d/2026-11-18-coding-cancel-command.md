`cogmo coding cancel <task-id>` cancels a coding task that has not ended, through the same conditional transition as the plan keyboard's Cancel, and writes `user_cancelled`. That frees the repo's admission slot, including for a task stuck at a status no run holds, such as `pending_verify`. A run still working on the task stops at its next status change. An already-ended task, an unknown id or a malformed id exits non-zero. The CLI and the Transport cancel now share one use case, `cancelCodingTask`.
