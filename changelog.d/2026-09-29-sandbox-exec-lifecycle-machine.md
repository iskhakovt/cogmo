Sandbox execs on every backend run through one lifecycle: a pure state machine driven over small backend adapters. A deadline, `dispose()` or the new `ExecOptions.signal` settles an exec at once, and teardown follows without holding it. Handles expose `exited`, which never rejects; `wait()` still throws, with one shared `ExecDisposedError`. Fixes: a Daytona exec hanging forever after a timeout when `deleteSession` failed; PTY timeouts that didn't bound upload, `createPty`, connect, `sendInput` or the stderr download; late PTY output re-arming the idle timer; verify and `git` stream readers whose unhandled rejections could crash the server on a transport failure; and local Docker reading a not-yet-reaped exec's null exit code as 0, which let a failing verify suite pass. Local Docker stops a timed-out or disposed command by signalling its process group from a second exec, since closing the attach socket left it running. Verify passes its timeout to the exec.
