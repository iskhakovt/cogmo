Codecov now sees integration-tier coverage in addition to unit. Previously the unit job uploaded `coverage/lcov.info` and the integration/e2e jobs uploaded nothing, so anything exercised primarily by `*.integration.test.ts` (transport adapters, attachment store, sandbox supervisor, db pool, telegram main entry, worktree orchestrator, etc.) showed as uncovered on the Codecov dashboard — driving the project number down to ~78.6% even though local unit coverage is already 84.5%.

The integration job in `.github/workflows/ci.yml` now runs `pnpm test:integration --coverage --coverage.reportsDirectory=coverage/integration` and uploads the resulting lcov to Codecov with `flags: integration`. The unit job's output is moved to `coverage/unit/lcov.info` for symmetry. Codecov merges per-flag lcovs line-by-line, so the project total reflects the union of what both tiers actually exercise, while per-flag breakdowns remain visible in the UI.

E2e is intentionally left without coverage. The cogmo binary in e2e runs inside a container subprocess, so capturing v8 coverage there would require `NODE_V8_COVERAGE` env + a mounted volume + a SIGTERM handler that calls `v8.takeCoverage()` before exit (testcontainers' `container.stop()` SIGTERMs Node, which doesn't flush coverage on signal exit). The complexity isn't justified given that `design/testing.md` defines e2e as a "binary boots, migrations apply, full stack smoke" tier — real logic coverage belongs to unit and integration.

Also added a `codecov.yml` at the repo root following Codecov's modern recommendations: `flag_management.default_rules.carryforward: true` so a skipped or flaked tier doesn't tank the project total (the previous flag's coverage is held over until that tier runs again); `ignore` paths for test infrastructure (`src/test/**`), generated/declarative files (Drizzle schemas, type-only modules, Inngest event definitions), and out-of-tree paths (`migrations/`, `scripts/`, `dev/`, `test/`); and `auto` targets with a 1% threshold on both project and patch status to absorb v8 sampling noise without masking real regressions. Validated against `https://codecov.io/validate`.
