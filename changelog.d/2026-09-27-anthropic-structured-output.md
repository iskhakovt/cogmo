The Anthropic adapter answers `responseFormat` with structured outputs (`output_config.format`) instead of a forced tool call, which Opus 5.5 and Fable 5.1 reject with a 400. The Observer's correction and memory extraction, rule consolidation and the pending-memory drain use structured outputs; pipeline compilation, whose schema has an open object, gets an unforced synthetic tool named in the system prompt.
