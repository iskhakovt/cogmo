The Anthropic adapter answers `responseFormat` with structured outputs (`output_config.format`) instead of a forced tool call, which Opus 5.5 and Fable 5.1 reject with a 400. Rule consolidation, the Observer's correction and memory extraction and the pending-memory drain go through structured outputs; pipeline compilation, whose schema has an open object, takes a synthetic tool under `tool_choice: auto`, named in the system prompt. The schema sent keeps `enum` and `const`; only the keywords Anthropic's grammar doesn't support, such as length and numeric bounds, move into descriptions, and `chatTyped`'s Zod validation enforces them. `chatTyped` refuses a reply cut off at the output cap or the context window, or a refusal, before parsing it, where `jsonrepair` could have closed cut-off JSON into a valid value. A live test runs both paths on Opus 5.5 and structured outputs on Sonnet 5.
