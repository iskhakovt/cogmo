The Anthropic adapter answers `responseFormat` with structured outputs (`output_config.format`) instead of a forced tool call, which Opus 5.5 and Fable 5.1 reject with a 400. Every `chatTyped` call goes through it: the Observer's correction and memory extraction, rule consolidation, the pending-memory drain and pipeline compilation. The schema passes through the SDK's transform, and `chatTyped`'s Zod validation covers the keywords the grammar lacks. A model without structured outputs (Sonnet 4, Opus 4) and a schema with an open object (pipeline compilation, for a stage's JSON output schema) take a synthetic tool under `tool_choice: auto`, named in the system prompt. A live test runs both paths on Opus 5.5 and structured outputs on Sonnet 5.
