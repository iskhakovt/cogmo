**Bug fix.** `cogmo serve` on `SANDBOX_BACKEND=daytona` was failing fatally at boot when the Daytona API was unreachable, even though the agent itself (Telegram, memory, tier-1 skills) doesn't need Daytona to handle a message. Root cause: `SkillRunnerImpl.create` eagerly constructed the tier-2 worker pool whenever a sandbox was wired, which meant `min: 1` workers got spawned synchronously at boot — burning a billable Daytona sandbox before the agent had answered a single message, and treating any spawn failure (transient daemon error, rate limit, image build hiccup) as fatal. The eager-warm comment cited "fail loud at boot for misconfig" but that calculus was written when sandbox = local-docker (free, on-host); for Daytona the trade-off inverts.

Pool init is now lazy — `SysboxWorkerPool.create` runs on first tier-2 invocation, not at boot. Concurrent first-callers share an in-flight promise; a transient Daytona blip clears the promise so the next caller retries (no permanent poisoning). Unreachable Daytona at boot is now non-fatal: cogmo serve comes up, tier-1 skills + every other agent surface work, and tier-2 invocations get the upstream error at the moment they fire instead of at boot.

Two new env vars to tune cost on managed backends:

- `COGMO_SKILLS_POOL_MIN` (default `0`, was hard-coded `1`). Always-warm worker count. Default change: workers exist iff there's an active or recently-active task. Trade-off: first tier-2 invocation per idle period pays a cold start (~1-2 s on Local-Docker, ~30 s warm-snapshot or 60-120 s first-build on Daytona). Set `1` for steady-state ~300 ms interactive latency at the cost of one always-running worker.
- `COGMO_SKILLS_POOL_IDLE_SHUTDOWN_MS` (default `1800000` = 30 min). Idle threshold before warm tier-2 workers above `min` are torn down. Daytona deployments should set lower (e.g. `300000` = 5 min) to release the billable sandbox sooner. Sweep cadence remains fixed at 60 s.

Bootstrap-daytona integration test simplified: the `NO_SANDBOX` workaround is gone (lazy init makes passing the daytona sandbox at boot safe), and a new regression assertion pins the cost-saving contract — `fakeSandbox.createCalls` is empty after `bootstrap()` because no tier-2 invocation has fired.
