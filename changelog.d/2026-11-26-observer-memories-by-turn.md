The Observer extracts memories turn by turn, on the same durable cursor as corrections (design/observation.md → Slice 2a): one model call per turn no fire has observed, with the exchange before it as context, for every kind of turn and for conversations of any length. A turn's facts are stored on its `turn_observations` row before they are retained, each under a Hindsight document id keyed on the turn and the fact's position, so a re-run re-sends them without a model call and a fact is retained once per turn that states it. A fact counts only when its `evidence` quotes the turn. While one of the user's memory rules binds a profile that can't see it, that profile's turns are held, and they are released once nothing binds them. A Hindsight outage pauses the phase without counting against the turn.

A fire with no turn to observe, no staged row and no failed phase writes no audit row, and `/reflect` then answers "Nothing new since the Observer last ran." Migrations `0093_observation_memories_values` and `0094_observation_memories` add the phase and start each conversation's memories cursor where the transcript-era audit rows show memory extraction last returned facts. The learning-loop cassette is re-recorded for the per-turn memory prompt.
