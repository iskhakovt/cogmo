Runtime image now ships `ca-certificates` and `openssh-client` alongside `git`, fixing `/repo add` flows that invoke `git clone` from inside the container. Without CA certificates HTTPS clones fail with `server certificate verification failed. CAfile: none`; without `openssh-client` SSH clones fail with `cannot run ssh: No such file or directory`. The previous Dockerfile installed `git` with `--no-install-recommends`, which suppressed both transitive dependencies — now they're explicit so the dependency stays visible if anyone re-tightens the install line.
