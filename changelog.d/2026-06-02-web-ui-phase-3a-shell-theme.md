Give the web cockpit its shell and its skin — Phase 3a. The SPA gains an inverted-L layout: a slim left section-nav (Chat / Memory / Agent / System) over a section pane, with a brand mark, a dark/light toggle, and a logout control in the nav foot. TanStack Router (code-based route tree, no codegen plugin) owns navigation — `/` redirects to `/chat`, `/chat` resolves the most-recent or a fresh conversation and redirects to `/chat/$conversationId`, and the streaming chat now lives inside its CHAT section rather than owning the whole window. Memory, Agent, and System route to placeholder stubs for now (Memory's hero screen is Phase 4; the Agent/System data screens are 3b).

A `cmdk` command palette (Cmd/Ctrl+K, Esc to close) jumps between sections and runs actions — new chat, toggle theme, log out. A per-tab id is minted once at the app root and threaded through the router via a small `AppProvider` context, so the palette and chat section share one tab identity and one logout path.

The visual layer is the Ledger design system: Tailwind v4 (`@tailwindcss/vite`, `@import "tailwindcss"`, `@theme inline`) with an OKLCH token ramp (bg / surface / ink / line / accent + ok/warn/bad trust states) exposed as utilities that flip at runtime off a `data-theme` attribute. Dark is the default; the toggle persists to localStorage and an inline pre-paint script in `index.html` applies the saved theme before first paint to avoid a flash. IBM Plex Sans/Mono are self-hosted via `@fontsource` (no Google CDN). Biome's CSS parser is switched to `tailwindDirectives` so it parses (and formats) the Tailwind v4 at-rules in the theme entry instead of choking on them.
