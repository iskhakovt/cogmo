The repository is now a pnpm workspace. The backend moved wholesale into `apps/server` (package name unchanged — still `cogmo`), a new root `package.json` is the workspace root owning husky + biome + proxy scripts, and `pnpm-workspace.yaml` globs `apps/*` + `packages/*`. `pnpm --filter cogmo deploy` and every cwd-relative runtime path (the LiteLLM snapshot, `vendor/`, `migrations/`) resolve unchanged, so the prod image and runtime behaviour are identical.

`packages/contracts` is a new types-only package mirroring the `Transport` surface — `StreamEvent`, the `TransportError` union, every admin DTO, and the enum/value shapes — for the future web client to import without pulling Zod or drizzle into a browser bundle. `isolatedDeclarations` rejects any runtime-value import, and `apps/server/src/test/contracts-parity.ts` asserts each mirror is mutually assignable with its backend type, so `pnpm typecheck` fails on any drift rather than letting the client copy silently desync.

`apps/web` is scaffolded as a stub (standalone tsconfig, a smoke import proving it resolves `@cogmo/contracts`); the Vite SPA itself lands later. The Dockerfile copies the member manifests before the frozen install and the `packages/contracts` source for the build; biome and `sysbox-e2e`'s path filters were repointed to the new layout.
