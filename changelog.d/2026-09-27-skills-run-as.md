Skills run as the user who invoked them. A chat invocation runs through the turn's scoped `Service`: `ctx.memory.recall` honours the profile's `memoryScope` and the restricted-class exclusion, and `ctx.memory.remember` stages into `pending_memories` for the Observer. `cogmo skills run` runs as the install owner with the default profile, and a cron fire runs as `skills.run_as_user_id` / `run_as_profile_id`, captured by the deploy that sets the schedule (its approver, or the owner) and backfilled for existing schedules. Approving a skill from Telegram records the tapper's `user_identities` row in `skill_deploys.approved_by`.
