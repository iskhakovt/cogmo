Every sandbox session states its network: `SessionSpec.network` is `"bridge"` or `"none"` (design/sandbox.md → Two interfaces). Local-Docker creates a `"none"` session with `NetworkMode: none`, so its only interface is loopback (it still mounts the Docker API proxy socket), and Daytona with `networkBlockAll`. The `skill-venvs-reaper` session now runs with `"none"`, since it only lists and removes directories; every other session keeps the backend's default network.
