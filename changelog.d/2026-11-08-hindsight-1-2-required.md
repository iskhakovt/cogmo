**Hindsight 1.2 is required.** `cogmo.hindsightCompat` is `>=1.2.0 <1.3.0`, so cogmo refuses to boot against a 1.1 server and the server moves with this release. The client is `~1.2.0` and both test images are `hindsight-api:1.2.0` (full and `-slim`). Nothing cogmo sends changes meaning: the client change is additive, and recall's new decision-model `rerank` options stay off unless a bank sets them. 1.2.0 adds no database migrations. A stored fact's text gains a `Where:` part when extraction finds a place, and a chunk too small to split fails its retain, which Hindsight's worker retries. The recorded extraction and embedding fixtures replay unchanged, and the routes open without the API key are the same.
