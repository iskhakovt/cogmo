`pnpm dev` now starts the web UI alongside the backend. The dev orchestrator (`scripts/dev-infra.ts`) spawns the Vite dev server for `apps/web` in addition to `cogmo serve`, so a single command brings up infra, the backend on `:9090`, and the SPA on `http://localhost:5173`. Vite proxies `/rpc` + `/api` to the backend (the proxy was already configured) so the browser sees one origin and the session cookie + `Sec-Fetch-Site: same-origin` survive the round-trip the CSRF gate requires. The backend is started with `WEB_INSECURE_COOKIES=1` so the unprefixed dev cookie is accepted on plain `http://localhost`, and the orchestrator prints the master-key-derived login token to paste into the UI. Both child processes share one lifecycle — Ctrl+C (or either exiting) tears the other down; containers keep running under `withReuse()`. A root `pnpm dev:web` script runs just the Vite server for when the backend is already up.
