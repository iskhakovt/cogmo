Sandbox public surface reshaped to the `SandboxClient` / `SandboxSession` split documented in [design/sandbox.md](design/sandbox.md) → Backend Architecture. The factory mints sessions, the session is the per-task handle. `SandboxClient<TState>` carries `backendId`, `capabilities`, `healthCheck`, `reconcileCrashedInstances`, `ensureImagePresent`, `create(spec)`, `resume(state)`, `tryResumeByTaskId(taskId)`, `delete(session)`, `deleteByTaskId(taskId)`, `serializeState`/`deserializeState`, `shutdown`. `SandboxSession<TState>` carries `state`, `exec(cmd, opts)` (buffered with size cap + `truncated` flag), and `execStreaming(cmd, opts)` (`stdout`/`stderr` Readables, `wait()`, `dispose()` for runaway-exec kill). The session-state discriminator (`type: "local-docker"`) and Zod schema (`LocalDockerSessionStateSchema`) round-trip through Postgres so `resume(state)` works across Inngest `step.run` boundaries. `LocalInProcessSandbox` becomes `LocalDockerSandboxClient` and implements the new shape against the same dockerode + sysbox + proxy plumbing. `SessionSpec` replaces `TaskContainerSpec` with optional `worktree`/`homeVolume`/`askpass` fields and a flat `expiresAt`. The orchestrator's `findLiveContainer` helper folds into `client.tryResumeByTaskId(taskId)` — backends own the discovery semantics. Coding orchestrator + verify-orchestrator + claude/verify/commit-push/backend helpers + skills runner + skills tier-2 sysbox host all migrated. Test fakes across 13 files rewritten to satisfy the new interface. 2317 unit tests pass; pre-existing Pyodide wall-clock flake is unrelated. No behavior change.
