`design/sandbox.md` → Proxy Design now separates what the Docker API proxy enforces today from a `[proposed]` authorization boundary. The boundary specifies an ownership model backed by store rows, a default-deny route table with a canonical forwarded request, a create and exec body allowlist read case-insensitively, upgrade-only raw piping, per-task caps, child-container rows inside the existing Container state machine, and a new Network and volume state machine, each with its failure modes, plus a deny-matrix test plan. The work is planned as five implementation slices in `todo.md`.
