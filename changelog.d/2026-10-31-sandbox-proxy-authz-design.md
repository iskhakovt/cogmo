`design/sandbox.md` → Proxy Design now separates what the Docker API proxy enforces today from a `[proposed]` authorization boundary. The boundary specifies an ownership model backed by `containers` rows, a default-deny route table, a create and exec body allowlist read case-insensitively, upgrade-only raw piping, and child-container rows inside the existing Container state machine, with their failure modes and a deny-matrix test plan. The work is planned as five implementation slices in `todo.md`.
