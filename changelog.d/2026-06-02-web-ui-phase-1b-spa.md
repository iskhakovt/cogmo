Turn `apps/web` into a real Vite 8 + React 19 SPA — the minimal proof that completes the Phase 1 acceptance demo. A password-style login posts the bootstrap token to `POST /api/session`, and once the cookie is set the app reads one Transport namespace (`models.list`) over an oRPC client and renders the list; a logout button deletes the session. The oRPC surface is hand-typed for the single read (a fully typed client over every namespace waits on a type-only router export in a later phase). The client sends `credentials: "include"` so the httpOnly session cookie rides every RPC; in dev, Vite proxies `/rpc` + `/api` to a running `cogmo serve` so the browser still sees one origin and the CSRF gate's `Sec-Fetch-Site: same-origin` holds.

The Dockerfile gains a final build stage (`pnpm --filter web build`) and copies the output into the runtime image at `apps/web/dist`, where sirv serves it from `WEB_STATIC_ROOT`; the deny-all `.dockerignore` allow-list grows to cover the SPA source. `vite` is pinned to an exact, vetted version (the `@vitejs/plugin-react` peer otherwise pulls a same-day release past the workspace's `minimumReleaseAge` supply-chain gate); react/react-dom/`@types/react` use mature caret floors. This shares one mature `vite` across the workspace, replacing the older copy vitest had been resolving.
