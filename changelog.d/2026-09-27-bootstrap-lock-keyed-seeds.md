`cogmo serve`, `cogmo seed` and `cogmo setup` migrate and seed under one session-level bootstrap lock, so concurrent runs apply them one at a time. The default profile and the direct and web channels are written through keyed inserts, the channels on a new unique index over fixed-identity channel types. Concurrent skills-repo bootstraps each install the pre-receive hook through their own temp file, and a boot racing the wizard reads the skills origin after its row snapshot, so it can't write an older URL back. An install already holding two direct or two web channels fails migration 0061 until the newer one is deleted.
