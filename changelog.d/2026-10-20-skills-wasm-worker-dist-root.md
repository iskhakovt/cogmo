**Tier-1 skills run from the release image.** tsup emits the Pyodide worker as `dist/worker-entry.js`, beside `dist/index.js` where the skills host is bundled, so the host's `./worker-entry.js` resolves. With the worker under `dist/skills/worker-wasm/`, every tier-1 invoke from the image failed at worker init with `Cannot find module '/app/dist/worker-entry.js'`; source-tier tests load the host from `src/` and never take that path.

`skills.e2e.test.ts` covers it: inside the app container it pushes a tier-1 skill branch to the bare skills repo, runs `cogmo skills register`, then `cogmo skills run` in a second process, and expects the skill's output.
