Tier-1 skills now run inside a boundary. Each task forks its own Node child under the permission model: the child may read the Pyodide distribution, the package cache and its lockfile's wheel directory and nothing else, spawn its one worker thread, and build no code from strings. The child starts with an empty environment; Pyodide's `js` module sees a frozen object holding two timer functions; `fetch`, `XMLHttpRequest` and `WebSocket` are deleted before skill code runs; linear memory past the skill's `memory_mb` (128 MiB by default) raises `MemoryError` and the interpreter survives; at the wall clock the host interrupts over IPC and then `SIGKILL`s the child's process group, and any result that arrives after the interrupt is `wall_clock_exceeded`. A child exits when its IPC channel closes; `cogmo serve` kills at boot the recorded process groups whose owner process is gone and whose child still runs, and leaves a live owner's children alone.

Dependencies no longer reach the network from the child. The host resolves `requirements.lock`: packages Pyodide bundles load from a package cache the host fills and verifies against `pyodide-lock.json`'s hashes before every run (Pyodide's own Node loader checks none), and every other package is a pure-Python wheel the host downloads, verifies against the lockfile's SHA-256 and publishes read-only under `.pyodide-wheels/<lockfile-hash>/`, written like the venvs (`tmp.<id>`, `.ready`, rename) and reaped by the same reachability rule. Register fetches them (a wheel that fails its hash or has no pure build rejects the register as `tier1_dependency_unavailable`; a network or cache failure only warns and the first run fetches) and load-tests native built-ins under the flags, rejecting one that cannot load as `tier1_incompatible_dependency`; a run whose packages cannot be made available fails as `tier1_packages_unavailable`. `wasm-lint` rejects imports of `js`, `pyodide_js`, `pyodide.ffi`, `pyodide.code`, `pyodide.http` and `micropip`.

`tier1Hardened` is set, so a tier-1 skill with no effects, secrets, network or unlisted dependencies no longer carries the `tier1_unhardened` reason; `auto` stays capped at `notify` until a review panel exists. `tier1MemoryBounded` stays false until the per-child cgroup ships.
