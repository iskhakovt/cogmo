OpenAI's reasoning models from GPT-5.5 serve chat turns on a direct OpenAI row: a request with tools goes at `reasoning_effort: "none"`, the only effort at which Chat Completions takes function tools. Every other request to an o-series or GPT-5+ model drops `temperature` with a once-per-model warning, so degraded-reply synthesis gets a written reply instead of the fixed fallback. GPT-6 Astra takes tools only on the Responses API and can't serve chat turns yet.
