OpenAI's reasoning models from GPT-5.5 serve chat turns on a direct OpenAI row. A request with tools or a temperature to a model with a `none` reasoning effort (GPT-5.1 onward) goes at `none`, the only effort at which Chat Completions takes function tools or a temperature other than 1, so degraded-reply synthesis gets a quick written reply at `temperature: 0`. The o-series, GPT-5, GPT-6 Astra and `chat-latest` drop `temperature` with a once-per-model warning, and `chat-latest` takes its output cap as `max_completion_tokens`. GPT-6 Astra takes tools only on the Responses API and can't serve chat turns yet.
