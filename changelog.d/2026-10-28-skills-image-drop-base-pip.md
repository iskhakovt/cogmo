**The `cogmo-skills` runtime image no longer ships the base image's pip.** Nothing in the image used it: the supervisor and every skill run in venvs without system site-packages, and uv does every resolve and install. Its vendored certifi, urllib3, msgpack and setuptools still reached Trivy, so each of their advisories became an image alert that only a pip release could close, most recently certifi's emSign root ([GHSA-6q48-6c7w-9gw2](https://github.com/advisories/GHSA-6q48-6c7w-9gw2)).
