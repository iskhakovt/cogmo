**Current frontier models resolve real limits.** `data/litellm-models.json` carries 3,012 entries refreshed from upstream LiteLLM, so `claude-opus-5-5`, `claude-fable-5-1`, `gpt-6-astra` / `-sol` / `-luna` and `x-ai/grok-4.7` each resolve their own context window and output cap, reported as `litellm` in `cogmo model list`. An id the snapshot doesn't know still resolves — to a conservative 128k/4k, with one `WARN` per id and `default` in the CLI's source column — which is a safe floor and a quiet one: a 1M-context model budgeted at 128k compacts turns that would have fit. Regenerate with `pnpm tsx scripts/refresh-litellm-models.ts`.

Bare and provider-prefixed ids are separate keys. `lookupLitellm` bridges `x-ai/` ↔ `xai/` and an `openrouter/` prefix, and falls back to the last path segment, but it does not invent a vendor namespace for a bare name: `x-ai/grok-4.7` resolves where `grok-4.7` does not, and `azure/gpt-5-codex` where `gpt-5-codex` does not. The snapshot mirrors upstream, so ids LiteLLM has retired — the Claude 3 family, Bedrock regional variants, dated GPT-4 previews — are absent here too, and a profile pinned to one lands on the conservative default until `cogmo model add --context N --max-output N` pins it.

A fresh install starts on `claude-sonnet-5`, exported as `DEFAULT_PROFILE_MODEL` rather than written as a literal, and `seed.test.ts` pins that the id it names resolves from the snapshot rather than the fallback. That guard is the only thing standing between a typo'd or unknown default and every conversation on the install compacting early, since nothing about the fallback is loud.

Cassette-replaying suites pin their own chat model. aimock's fixture match key includes `model` and enforces it whenever a fixture carries one, so the skill-authoring integration test and the e2e stack point the profile they drive at `CASSETTE_CHAT_MODEL` and route that id — leaving the seeded default free to move without turning recorded turns into strict-mode 503s, which surface as a 60-second `vi.waitFor` timeout that names nothing.

Six cassettes recorded on 2026-05-25 carried skill-authoring's prompts keyed on `claude-sonnet-4-6`, alongside the 2026-08-18 recording of the same prompts keyed on `claude-sonnet-5` — two generations of one suite's cassette, distinguished only by the model in their match key. The older set is deleted. While both were present, any profile left on the earlier model replayed the stale generation, and what surfaced was three suites timing out in `vi.waitFor` with nothing naming the cause.
