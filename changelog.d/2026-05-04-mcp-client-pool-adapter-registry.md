MCP client + pool + adapter + registry (Phase A, PR 2 of 3). Adds the runtime layer on top of PR 1's store. New `src/mcp/approval.ts` — `hashToolSchema(snapshot)` produces a stable sha256 over canonicalized `{description, inputSchema}` (recursive key sort; arrays preserve order so `required: ["a","b"]` and `["b","a"]` hash differently — order-significant per JSON Schema), and `diffPins(currentTools, pinned)` is a pure function returning `{added, removed, mutated, unchanged}` for the rug-pull detection path. New `src/mcp/client/transport.ts` — `createTransport(config, secrets)` factory wrapping `StdioClientTransport`; resolves `McpValueSource` env entries (literal/secret) at construction; pipes server stderr; throws "deferred to Phase C" for `http`/`sse` rather than silently misbehaving. New `src/mcp/client/runner.ts` — `Runner` interface + `HostRunner` impl that constructs an SDK `Client`, hands it the transport, and returns a connected `McpConnection`; cleans up on connect failure. New `src/mcp/client/client.ts` — `McpConnection` interface (the layer the rest of the module depends on, decoupled from the SDK so pool/adapter/registry are unit-testable with fake connections) + `SdkMcpConnection` implementation forwarding stderr to structured log, surfacing transport-close as a subscribable event, wiring `tools/list_changed` notifications, passing per-call `timeoutMs` straight through to the SDK's native `RequestOptions.timeout`. New `src/mcp/client/pool.ts` — `McpConnectionPool` is the process-singleton: lazy-spawn on first `getConnection`, reuse-on-second, per-server in-flight mutex via `#connecting` map (concurrent gets share the same spawn promise); transport-close flips the entry to `closed` only when the live entry still references THAT connection (don't downgrade a fresh reconnect); reconnect-once policy (one retry on next call after close, second consecutive failure → `unhealthy` with the error message persisted, subsequent calls fail fast); `evict(id)` closes + forgets, `reset(id)` clears unhealthy state for operator retry, `close()` shuts down all live connections; periodic idle sweep at `evictionIntervalMs` closes any connection whose `lastUsedAt` is older than `idleEvictionMs` (sweep timer `unref`'d so it doesn't pin the process); injectable clock for tests. Recovers from the `pending.finally(...)` chain re-rejecting via a tail `.catch(() => {})` so the cleanup chain doesn't surface unhandled rejections when the original promise was rejected and handled by the caller. New `src/mcp/adapter.ts` — `mcpDescriptorToToolSpec({server, descriptor, pool, timeoutMs})` produces a `ToolSpec` with `name = mcp__<server>__<tool>`, `durable: true` (MCP servers are non-deterministic; Inngest step memoization gives exactly-once on retry), `inputSchema` forced to `type: "object"`; handler dispatches via `pool.getConnection(serverId).callTool(...)` and serializes the SDK `CallToolResult` (joins text content blocks; falls back to `JSON.stringify(structuredContent)` then to the raw content array; throws on `isError: true` so the agent loop's catch wraps as `tool_result` with `isError`). New `src/mcp/registry.ts` — `McpRegistry` interface + `McpRegistryImpl`. `resolveTools({toolGlobs, budget?})` is the orchestrator-facing per-turn API: empty globs → empty result; otherwise loads enabled+approved servers, joins approved tool pins, materializes each as a `ToolSpec` only if the composed `mcp__server__tool` name matches a glob, sorts alphabetically, caps at `toolBudget` (default 25 from PR 1's locked-in decision) and emits a `WARN` listing the dropped tools. `approveServer(id)` is the connect+pin path — resets unhealthy pool state, opens a connection, lists tools, applies the pinning rule (unchanged → preserve approval status; new or mutated → `pending`; never silently approve a changed schema), deletes pins for tools that vanished, flips `mcp_servers.approval_status = approved`. `approveTool/rejectTool` are thin store passthroughs. `removeServer` evicts the pool entry first, then deletes the row (cascade handles pins). `start()`/`stop()` boot/shutdown the pool.
