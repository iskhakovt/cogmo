`pnpm test:mutation:skills` runs mutmut over the skills runtime with every mutant in a container, and re-runs each mutant mutmut didn't kill against the whole suite, which includes the black-box tests that start the supervisor as a subprocess. It writes `images/skills/mutation-report.txt`: the survivors' diffs, then the mutants counted as killed by a timeout, a signal, an interrupted run or a failed collection, and any that failed to run.
