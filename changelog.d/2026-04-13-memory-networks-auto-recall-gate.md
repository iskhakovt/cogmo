Memory networks + auto-recall gate. Four memory networks (world, bank, opinion, observation) implemented as Hindsight tags (`network:<type>`). Observer now extracts facts from conversation transcripts via `chatTyped()` with Zod schema, classifies into networks, and retains to Hindsight with `observation_scopes: "per_tag"` for per-network consolidation. New `retainBatch` on `MemoryProvider` interface. `memory_retain` tool defaults to `network:world`. Auto-recall gated by profile-level `auto_recall` column (`off/always/heuristic/llm`, default `heuristic`). Heuristic gate skips greetings, acks, and continuations — pure function, zero latency. LLM gate stubbed for future use. `tagsMatch` added to `RecallOptions`/`ReflectOptions` and passed through Hindsight adapter. Migration: `profiles.auto_recall` column.
