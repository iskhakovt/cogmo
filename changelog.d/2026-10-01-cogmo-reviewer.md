`/cogmo-review` runs `cogmo-reviewer`, a read-only subagent that checks a change against the repo's own rules rather than for general bugs. `code <PR | branch | range>` reports a checklist (idioms, architecture and DDD boundaries, state machines, Inngest replay safety, data, tests, bookkeeping) as compliant / violation / n/a, each violation citing the rule file and a location, premise-checked and marked CONFIRMED or PLAUSIBLE. `design <path>` checks a design doc against `state-machines.md` "Design before code". The agent reads the rule files at runtime, so it tracks them as they change; a `PreToolUse` hook (`.claude/hooks/readonly-bash.sh`) limits its Bash to reading commands. Sub-agent briefs now ask builders to self-audit with it, and it runs alongside `/code-review` before a PR opens.
