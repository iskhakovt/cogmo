- `turnLogger` is now required on `AgentLoopParams` (and `StreamingAgentLoopParams`) — the optional-with-`?? logger`-fallback shape is gone. Production already wires it via `handle-message`'s per-invocation `logger.child({ runId, conversationId })`; the optionality was a tests-only convenience that hid the contract. Every test call site now passes `turnLogger: logger` (or a `mock<Logger>()` for the plumbing assertions). Closes the `p3` decision flagged on PR #257 round 2 — at this codebase's type-rigor culture, compile-time enforcement beats a runtime fallback that silently dropped `runId` + `conversationId` from any future miss-wired caller.
