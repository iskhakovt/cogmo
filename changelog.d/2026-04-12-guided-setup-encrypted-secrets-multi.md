Guided setup + encrypted secrets + multi-provider LLM. New `src/secrets/` module: AES-256-GCM encryption via `@noble/ciphers` (Cure53-audited), HKDF-SHA256 key derivation via `@noble/hashes`, `secrets` table for encrypted credential storage, `ConfigResolver` (DB-first env-fallback), `_FILE` Docker secrets convention, `gen-key` CLI subcommand. New `src/setup/` module: interactive wizard (`cogmo setup`) via `@clack/prompts` — configures LLM provider (Anthropic/OpenRouter/OpenAI/custom with validation), Telegram channel + allowlist, optional web tool keys. Re-runnable (Keep/Modify/Skip per step), `--reset` scopes, `--non-interactive` mode. Multi-provider LLM: `llm_providers` table + `model_providers` routing table (position-based priority, `UNIQUE(model, position)` prevents ties). Provider dispatch in bootstrap resolves model → best provider → decrypts key → constructs adapter. `ANTHROPIC_API_KEY` removed from env (DB-only, no backward compat). Identity resolution wired in transport layer: `createConversation` calls `resolveUser`, Telegram adapter rejects unauthorized users via `user_identities` rows. Channel CRUD: `createIdentity`, `updateChannelCredentials`, `removeChannel` (cascading FK delete). Seed refactored to `src/setup/seed.ts` with named exports. `.dockerignore` switched to deny-all/allow-list. `profiles.summarization_model` replaces `SUMMARIZATION_MODEL` env var. Design docs: `design/providers.md`, `design/setup.md`, expanded `design/infrastructure.md` Secrets section.
