**Hindsight 1.3 is required.** `cogmo.hindsightCompat` is `>=1.3.0 <1.4.0` and cogmo refuses to boot against a 1.2 server, so upgrade Hindsight to 1.3 with this release. Back its database up first: 1.3.0 runs three migrations, so going back to 1.2 means restoring that backup. Hindsight writes each extracted fact in the language of its source text. Knowledge banks are on by default, behind the API key; cogmo uses none of them, and `HINDSIGHT_API_ENABLE_KB=false` turns their HTTP routes off.
