**A file a tier-2 task writes to `$HOME` reaches neither a later task's imports nor a venv populate's uv configuration.** The supervisor starts as `python3 -I -u -m cogmo_skills_runtime`, which keeps its cwd, `$HOME`, off the `sys.path` every task on the worker inherits, so a planted `csv.py` cannot run inside the next task that imports `csv` with that task's inputs and `ctx` in reach; `-I` also ignores `PYTHON*` variables, and `-u` covers the image's `PYTHONUNBUFFERED`. The populate and reap scripts run from `/` with `UV_NO_CONFIG=1`, so uv reads no `uv.toml` or `.python-version` from `$HOME` or `~/.config/uv/`. The sysbox tier plants a module and uv configuration and checks that neither takes effect.
