**Node 26 is the runtime and the engine floor**, as of its Active LTS on 2026-10-28. The runtime image, devbase, CI, the dev shell and the bundle target run 26, and `engines.node` is `>=26.0.0` with `@types/node` 26 to match. The Node 26 image ships no corepack or yarn, so the runtime stage only strips npm. `Temporal` is on by default; a package types it by adding `esnext.temporal` to its `lib`, and `design/tooling.md` lists it ahead of any date library.
