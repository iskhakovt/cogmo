The Observer extracts only what it hasn't processed. `conversations` carries a cursor per extraction phase, `corrections_observed_through` and `memories_observed_through`, so an idle fire reads the messages after it, with the widest stored summary that ends before them and the last 10 earlier messages as labelled context. A re-read transcript no longer reinforces an old correction again or stores its facts again.

- **Evidence.** New messages are numbered, and every extracted correction and fact cites the one it comes from (`sourceMessage`). An item citing the earlier conversation, or none, is dropped and counted in `droppedForContext`.
- **Contradictions** key on the message they cite (`steering_rules.contradicted_by_message_id`): re-extracting the same message never counts twice, and a contradiction from a different message retires a learning rule an earlier one reset.
- **Retry-safe memories.** Each fact's Hindsight document id comes from the conversation, the message it cites and its position among that message's facts, so a re-run extraction replaces its own documents. Memory extraction fails its chunk on a failed model call instead of reporting nothing found.
- **Chunks.** A window larger than a quarter of the extraction model's input budget (at least 1,000 tokens) is split at message boundaries and planned in pages; oversized messages are cut with a marker. A fire extracts at most 3 chunks per phase and advances that phase's cursor after each, so a failed phase keeps its window for the next fire. A model too small for that skips extraction and the audit row records `modelBudgetTooSmall`.
- **Phase isolation.** Each phase plans inside its own failure boundary, and a failed `/reflect` still records the fire before reporting. `newMessages` counts the messages whose cursor advanced.
- **Held memories.** A third-party fire bound by a user's `memory` rule leaves the memories cursor where it is, so those messages stay unextracted rather than lost.
- **Nothing new.** A fire with both cursors caught up skips extraction and still drains; `/reflect` answers "Nothing new since the Observer last ran."

Migration 0068 adds the cursors and the marker. Migration 0069 starts each phase's cursor at the newest message created before the latest fire that extracted that phase began (a fire's start is its audit row's time less `durationMs`, or 10 minutes when that's missing); a fire that failed the phase, found the model too small or held memories doesn't count. Conversations never observed start with no cursor and are read from the start. See design/evolution.md → Observation Window.
