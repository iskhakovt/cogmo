**Every install takes only releases at least 7 days old.** `minimumReleaseAge` in `pnpm-workspace.yaml` is 7 days, matching Dependabot's npm `cooldown`, so a local `pnpm install` or `pnpm update` resolves to the same soaked versions a Dependabot PR would, and every install, CI and the image build included, re-checks the lockfile against it. A release that has to land sooner, such as a security patch, gets a `name@version` entry in `minimumReleaseAgeExclude` until it is 7 days old. `release-age.test.ts` holds the two settings equal.
