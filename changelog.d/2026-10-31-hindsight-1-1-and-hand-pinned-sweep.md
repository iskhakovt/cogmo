**Hindsight 1.1 is required.** `cogmo.hindsightCompat` is `>=1.1.0 <1.2.0`, so cogmo refuses to boot against a 1.0 server and the server moves with this release. The client is `~1.1.0` and both test images are `hindsight-api:1.1.0` (full and `-slim`). Nothing cogmo sends changes meaning: the client change is additive, recall's new `prefer_observations` default stays off unless a bank sets it, and every `tags_match` value the adapter sends is still accepted. 1.1.0 adds five Postgres migrations, one of which clears placeholder memory dates, so roll Hindsight back from a database backup rather than by re-pinning the image. The recorded extraction and embedding fixtures replay unchanged, and the routes open without the API key are the same.
