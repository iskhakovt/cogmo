The skill cron ticker retries its fan-out. It advances each due row's `next_run_at` in a memoized step and sends the fire events in a later one; with no retry budget a transient send failure ended the run, the advanced rows were past `now()`, and that fire was lost while the row said it had fired. The function now retries, so a failed send replays against the memoized advance and the deterministic event ids deduplicate it on the bus. Cron is no longer described as the recovery for an advanced row.
