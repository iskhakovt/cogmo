Cleanup is a hybrid event-driven primary + cron safety-net design (per industry-standard Renovate/Dependabot/GitHub-native patterns). New `coding/task/failed` event emits from every failure path (plan + execute + verify try-blocks and outer-catches). New `cleanup-run-branch.ts` Inngest function subscribes to both `coding/task/pr-opened` and `coding/task/failed` (idempotency keyed on `taskId` so simultaneous fires collapse to one execution) and calls `octokit.git.deleteRef` with 404+422 swallowed; default retries handle transient 5xx / secondary rate-limits. Weekly `cleanup-orphan-run-branches.ts` cron at `0 4 * * 0` lists managed coding repos, fans out via `step.sendEvent` (one event per repo, per-repo handler with its own retry lane + concurrency limit of 2), lists `cogmo/run/*` refs via `octokit.git.listMatchingRefs`, joins with `coding_tasks`, and force-deletes refs whose task is terminal AND >7d old OR has no row at all. Non-terminal tasks are never swept — stuck approvals belong to the user.
