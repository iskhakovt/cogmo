Integration test files are isolated from each other. Each gets a database cloned from a template `globalSetup` migrates once, seeded with its own user (and so its own Hindsight bank), and an llmock serving only its cassette, `test/fixtures/recorded/suites/<file>/`. Hindsight's calls replay from one `hindsight/` cassette on the llmock the container reaches; the e2e stack has its own. A request a cassette cannot answer fails the test that sent it, naming the request's key and the closest fixtures with where each differs, and a file that passes every test fails if its cassette holds a recording nothing requested. That check found one stale recording, which is deleted, and `skill-authoring` points only the seeded org profile at the cassette model. The tier's wall time is unchanged.
