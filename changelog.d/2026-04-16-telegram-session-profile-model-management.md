Telegram session/profile/model management. Six new Telegram commands: `/sessions` (inline keyboard ≤10 convs, numbered text >10), `/resume <alias>`, `/name <alias>` (`-` clears), `/end`, `/profile [list\|switch\|new\|edit\|delete]`, `/model [<model>]`, plus `/cancel` for mid-dialog abort. Interactive multi-turn FSM for `/profile new|edit` (prompt → model → confirm; `skip` keeps current in edit mode; in-memory per chat — restart-mid-dialog loses draft, deliberate v0 tradeoff). `bot.on("message:text")` intercepts dialog input at the top so free-form replies during the FSM never reach the agent (regression-tested). Schema: `profiles.user_id UUID NULL FK → users` + `UNIQUE(user_id, name) NULLS NOT DISTINCT` (existing rows → org profiles visible to all, read-only via Transport); `model_providers.user_selectable BOOLEAN NOT NULL` (gates `/model` picker and `profiles.update({model})` validation); `messages.profile_id UUID NOT NULL FK → profiles` (backfilled from `conversations.profile_id`); `messages.model TEXT NOT NULL` with `'<legacy>'` sentinel backfill (no DEFAULT — every insert stamps explicitly); new `aliases` table with `UNIQUE(user_id, alias)`. Per-turn snapshot stamping in `handle-message.ts`: new `load-turn-snapshot` step reads `conv.profile_id` + `profile.model` once at turn-start, stamps every message produced by the turn (user batch + intermediate + final assistant) — mid-turn `/profile switch` or `profile.model` edits take effect on the *next* turn. `TransportError` extended with 7 codes (`profile_not_found` / `profile_in_use` / `profile_name_taken` / `model_unavailable` / `alias_taken` / `operation_not_permitted` / `access_denied`). New Transport methods: top-level `resumeConversation(address, handle, {alias\|conversationId})`; namespaced `conversations.{list, getCurrent, setAlias, setProfile}`, `profiles.{list, create, update, delete}`, `models.list`. All profile mutations enforce caller-owns ACL — org profiles (`user_id IS NULL`) always reject with `access_denied`; org-level CRUD happens out-of-band via psql/wizard. New `UniqueViolationError` + `translateUniqueViolation` helper walks Drizzle's `DrizzleQueryError.cause` to surface Postgres 23505 as typed errors, which Transport maps to `alias_taken` / `profile_name_taken`. `AgentStore.getProfile` broadened to return full `Profile` (incl. `userId`, `name`). New files: `src/transport/adapters/telegram/{commands,sessions-ux,profile-dialog}.ts` + tests; `src/agent/store/errors.ts`. Wizard + non-interactive seed + e2e-setup all pass `user_selectable: true` on `model_providers` inserts. Migration `0007_odd_true_believers.sql` with 3-phase ADD→backfill→SET NOT NULL. 72 new unit tests (schema, admin ACL, session UX, command handlers, FSM). Docs already updated in prior iteration (`design/transport/{adapters,telegram,sessions,overview}.md`, `design/providers.md`, `design/data-model.md`).
