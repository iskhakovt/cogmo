Every test container is defined in `apps/server/dev/containers.ts`, so each image pin has one home. The Gitea container from the verify-orchestrator integration test is the `gitea()` factory again, and the keyed `inngest start` container from the boot-check integration test is `inngestKeyed()`, sharing one Inngest image pin with `inngest()`; `version-pins.test.ts` asserts that pin appears nowhere else. A new Biome plugin, `no-inline-test-container`, flags `new GenericContainer(...)` and `GenericContainer.fromDockerfile(...)` anywhere else; `test/e2e-setup.ts` is exempt, since it runs the app image it bakes. `dev/` is now typechecked with `src/`, which `src/` tests importing it requires.
