The Observer's correction-extraction and rule-consolidation prompts list existing steering rules under ordinal labels (`R1`…`Rn`) instead of their database ids. The model echoes a label, which the extractor and consolidator map back to the rule id; a reinforcement, contradiction or merge group whose label names no listed rule is skipped with a warning. Labels follow priority, then rule text, with the id only breaking an exact tie, so the prompts are byte-stable across runs and a recorded fixture can replay them. A short label is also easy for the model to copy exactly, where a slip in a 36-character UUID drops the match.
