**pnpm 12.8.1** is the version for the workspace (`packageManager`), the app image build (via corepack) and `cogmo-devbase`. `pnpm deploy --prod --no-optional` ships the same package files it did under pnpm 11; only the `.bin` shims differ. devbase copies pnpm's native executable and its `dist/` from the official `ghcr.io/pnpm/pnpm` image, pinned in `docker-bake.hcl` by `PNPM_VERSION` and `PNPM_DIGEST` the same way uv is. `pnpx` and `pnx` are two-line `pnpm dlx` scripts. The build fails unless `pnpm --version` equals `PNPM_VERSION`, because BuildKit ignores the tag beside a digest. `pnpm-workspace.yaml` sets `pmOnFail: ignore`, which keeps `pnpm-lock.yaml` a single YAML document. pnpm 12's environment document would otherwise come first, and GitHub's dependency graph reads only the first document, so Dependabot alerts would see no dependencies. Corepack and `pnpm/action-setup` still run exactly the pinned version.
