**pnpm 12.8.1** is the version for the workspace (`packageManager`), the app image build (via corepack) and `cogmo-devbase` (bake's `PNPM_VERSION`). `pnpm deploy --prod --no-optional` ships the same package files it did under pnpm 11; only the `.bin` shims differ. devbase installs pnpm with `--allow-scripts=pnpm` so its install script puts the native binary in place, and the build fails unless `pnpm` resolves to that ELF binary. `pnpm-workspace.yaml` sets `pmOnFail: ignore`, which keeps `pnpm-lock.yaml` a single YAML document. pnpm 12's environment document would otherwise come first, and GitHub's dependency graph reads only the first document, so Dependabot alerts would see no dependencies. Corepack and `pnpm/action-setup` still run exactly the pinned version.
