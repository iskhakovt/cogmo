Agent-facing guardrails: two hooks that enforce what was previously advisory, a skill carrying the dependency-sweep procedure, and a sub-agent brief checklist.

**Formatting is enforced rather than remembered.** A `PostToolUse` hook runs `biome check --write` on every file written through Edit or Write. CI runs `biome check --error-on-warnings`, so an unformatted file is a red build; applying the formatter on the way out means edits land clean instead of the formatting surfacing a step later.

It resolves biome deliberately. `node_modules/.bin/biome` is a shell wrapper whose last act is `exec node`, so it exits 127 wherever node is absent from PATH — and a hook treating 127 as "nothing to do" stops formatting without ever saying so. The native per-platform executable needs no node and runs in 9ms against the wrapper's ~200ms, so it comes first. Version matters too: more than one `@biomejs/biome` can be installed in a workspace, and only the one `node_modules/@biomejs/biome` resolves to is the version CI lints with, so the resolver keys on that rather than taking the newest on disk.

**A `Stop` hook refuses to end a turn on a red lint.** The per-edit hook covers Edit and Write, but changes arrive other ways — a script rewriting a manifest, a generated migration, a sub-agent's edits — and a whole-repo pass costs ~1.5s. It mirrors the `lint` script's `--error-on-warnings` so the gate and CI agree on what counts as red.

Exit 2 on `Stop` resumes the conversation instead of ending it, and the event carries no `stop_hook_active` flag, so the hook needs its own cycle breaker: it reports a given failure once and lets an unchanged one through, which keeps it from trapping a turn deliberately ended red — pausing for a question, handing back partial work. The key is the failure text with durations normalised out, not a working-tree hash: `git diff HEAD` is blind to untracked files and would mistake a half-fixed new file for the state it already reported, and biome's own "Checked N files in Xms" sign-off would otherwise make every run hash differently and defeat the guard. An unresolvable biome is itself reported, because a gate that cannot run must not read as a clean tree.

Typecheck is deliberately absent from both hooks. It measures 30–37s on this repo even warm, and filtering to one package is no cheaper because the server is the bulk of it — too much to charge every turn end. It stays in the pre-PR gate list.

**`/dependency-sweep` carries the procedure.** A skill body loads only when used, so the sweep's accumulated detail costs nothing until it is needed: the order groups are committed in, the per-major behavioural diff that a green build cannot substitute for, the specific library semantics worth reading source for, override retirement, the fixture re-recording traps, and a table of what each gate actually covers — including that none of them builds the image or bundles the SPA.

**Sub-agent briefs get a checklist** in `.claude/rules/`: verify the path before writing, report a verdict before a fix, confirm a regression test red before green, name the gates and their limits, keep hands off shared bookkeeping, and give each agent a disjoint file set rather than running the full suite alongside them.
