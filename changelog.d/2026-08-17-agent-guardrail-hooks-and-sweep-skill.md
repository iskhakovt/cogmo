Agent-facing guardrails: two hooks that enforce what was previously advisory, a skill carrying the dependency-sweep procedure, and a sub-agent brief checklist.

**Formatting is enforced rather than remembered.** A `PostToolUse` hook runs `biome check --write` on every file written through Edit or Write. CI runs `biome check --error-on-warnings`, so an unformatted file is a red build; applying the formatter on the way out means edits land clean instead of the formatting surfacing a step later.

It resolves biome deliberately. `node_modules/.bin/biome` is a shell wrapper whose last act is `exec node`, so it exits 127 wherever node is absent from PATH — and a hook treating 127 as "nothing to do" stops formatting without ever saying so. The native per-platform executable needs no node and runs in 9ms against the wrapper's ~200ms, so it comes first. It is found by following the symlink pnpm already maintains — whatever `node_modules/@biomejs/biome` resolves to is by construction the version the repo lints with, and the native binary sits beside it — rather than by rebuilding the virtual-store path from a manifest read. More than one `@biomejs/biome` can be installed in a workspace, so "newest on disk" would lint to a different biome's rules than CI; following the link is pinned to the right one without saying so, and keeps working under hoisted layouts, npm, and a custom `virtual-store-dir`.

**A `Stop` hook refuses to end a turn on a red lint.** The per-edit hook covers Edit and Write, but changes arrive other ways — a script rewriting a manifest, a generated migration, a sub-agent's edits — and a whole-repo pass costs ~1.5s. It mirrors the `lint` script's `--error-on-warnings` so the gate and CI agree on what counts as red.

Exit 2 on `Stop` resumes the conversation instead of ending it, so a gate that blocked unconditionally would trap a turn deliberately ended red — pausing for a question, handing back partial work. Breaking that cycle is the harness's job, not the hook's: Claude Code sets `stop_hook_active` on the payload once a Stop hook has blocked, its own guidance is to return success while that is true, and it caps consecutive blocks via `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP`. The hook checks the flag and stands aside. An unresolvable biome is itself reported, because a gate that cannot run must not read as a clean tree.

Both hooks take the tree from `CLAUDE_PROJECT_DIR`, falling back to `git rev-parse --show-toplevel`. Neither "walk up to the first `node_modules`" nor "use the script's own location" survives contact with this repo: every workspace member has its own `node_modules`, so the first roots at `apps/server` whenever that is the cwd, and the second always names the main checkout, so a session in a linked worktree would be told about a tree it is not editing. The Stop gate then runs from that root, and the format hook does too — biome discovers `biome.json` from the working directory, so invoked from anywhere else it formats to built-in defaults, writing tabs into a repo that uses two spaces and manufacturing the red build it exists to prevent.

Typecheck is deliberately absent from both hooks. It measures 30–37s on this repo even warm, and filtering to one package is no cheaper because the server is the bulk of it — too much to charge every turn end. It stays in the pre-PR gate list.

**`/dependency-sweep` carries the procedure.** A skill body loads only when used, so the sweep's accumulated detail costs nothing until it is needed: the order groups are committed in, the per-major behavioural diff that a green build cannot substitute for, the specific library semantics worth reading source for, override retirement, the fixture re-recording traps, and a table of what each gate actually covers — including that none of them builds the image or bundles the SPA.

**Sub-agent briefs get a checklist** in `.claude/rules/`: verify the path before writing, report a verdict before a fix, confirm a regression test red before green, name the gates and their limits, keep hands off shared bookkeeping, and give each agent a disjoint file set rather than running the full suite alongside them.
