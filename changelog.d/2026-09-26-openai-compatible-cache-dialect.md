OpenAI-compatible providers map the cache intent through `llm_providers.attrs.cacheDialect` (`openrouter | openai | xai | none`), which replaces the `promptCaching` boolean. OpenRouter gets `session_id` on every model, with a system-prompt `cache_control` marker on `anthropic/` models (plus the top-level field at the intent's TTL) and on `google/` models. OpenAI gets `prompt_cache_key`, and xAI the `x-grok-conv-id` header. Gemini takes the system marker because a marker on the last message measured as a fresh cache write on every request. `addProvider` derives the dialect from the base-URL host, non-interactive setup now goes through it, and `--cache-dialect` / `COGMO_LLM_CACHE_DIALECT` override it. Migration `0057` applies the same host rule to existing rows. Live scenario D measured cache reads on OpenRouter (Claude Sonnet 5, Grok 4.3, Gemini 2.5 Flash) and OpenAI (`gpt-4.1-nano`).
