The skill workers' host side runs on one pure state machine shared by both tiers, and a task's result comes back as a value with its exit outcome. The pool replaces a dead worker at once, back up to `min`, and keeps its container, counted toward `max`, until any task using it returns. After three workers in a row die on their own before any task, within a minute of their handshake, only the sweep replaces dead workers until a task returns with its worker alive. A failed spawn fails one acquire and spawns for the next queued one, and disposing the pool waits for teardowns already under way. A Pyodide worker thread that crashes or exits mid-task fails its task at once, and a worker whose first frame is malformed is refused at once. An exec socket error fails its task as a value: `dispatcher_error: transport: …`, or `skill_venv_transport_failed` during a venv install.
