The skill workers' host side runs on one pure state machine shared by both tiers: a task's result comes back as a value with its exit outcome, and the pool replaces a worker the moment it dies, keeping its container, counted toward `max`, until any task using it returns. After three workers in a row die on their own within a minute of starting and before any task, the pool replaces dead workers only on the sweep until a task completes. A failed spawn fails one queued acquire and spawns for the next, and disposing the pool waits for teardowns already under way. A Pyodide worker thread that crashes or exits mid-task fails its task at once, and a worker whose first frame is malformed is refused at once. An exec socket error fails the task as a value instead of crashing the process.
