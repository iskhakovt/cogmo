**Telegram replies when a file is over the bot download limit.** A photo, voice note or document over 20 MiB, by its declared `file_size` or by `getFile`'s "file is too big" refusal, gets "That file is too large to open. Telegram bots can download files up to 20 MB." instead of silence; a document with a declared size keeps its size-only placeholder route to the agent. The limit holds for every Bot API server Cogmo downloads from: only `--local` mode lifts it, and the adapter refuses that mode. The reply goes out before the identity check, so an unauthorized sender gets it too, as with command replies.

**`McpRegistry.resolveTools` reads every approved tool pin in one query** (`McpStore.listApprovedToolPins`, a join of pins to enabled, approved servers) inside one transaction, and builds its budgeted list without mutating it in place.
