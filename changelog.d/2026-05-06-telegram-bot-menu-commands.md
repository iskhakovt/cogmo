Telegram adapter now calls `setMyCommands` at startup so the in-app command menu (and the `/` autocomplete popup) lists the bot's commands instead of being empty. Twelve commands registered: conversation control (`/new`, `/sessions`, `/resume`, `/name`, `/end`), profile/model (`/profile`, `/model`), integrations (`/repo`, `/mcp`), and admin (`/repair`, `/cancel`, `/start`). Idempotent — Telegram replaces the list on each call. Failures are logged and swallowed so the bot still starts if the API rejects the call.
