**The runtime image takes every build arg from bake**, as devbase and skills do: the root `Dockerfile` declares `PNPM_VERSION`, `PNPM_DIGEST` and `VERSION` without defaults, so `docker-bake.hcl` holds their only copy, and `docker-bake.integration.test.ts` checks all three images the same way. A plain `docker build .` fails at the pnpm `FROM`; build locally with `docker buildx bake --load --set cogmo-e2e.tags=cogmo cogmo-e2e` (`DEPLOYMENT.md`).
