**Cogmo runs against Hindsight 1.0.0 and refuses a 0.x server, so upgrade Hindsight to 1.0.x in the same deploy.** The client is `~1.0.0`, the dev and test images are `hindsight-api:1.0.0` (full and `-slim`), and `cogmo.hindsightCompat` is `>=1.0.0 <1.1.0`. The range is one minor wide because upstream calls the 1.x API stable but publishes no versioning policy. Dependabot skips client minors and majors, so a client minor moves only with the image pins and the range.

1.0.0's breaking API change refuses tag-scoped callers on whole-bank operations. Cogmo's callers are unscoped: the API-key tenant extension runs without an operation validator. 0.10.3 and 1.0.0 add no Postgres migrations.
