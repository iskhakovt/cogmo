**Cogmo runs against Hindsight 1.0.0.** The client is `~1.0.0`, both test images are `hindsight-api:1.0.0` (full and `-slim`), and `cogmo.hindsightCompat` is `>=1.0.0 <1.1.0`, so the server moves with this release. The range is one minor wide: upstream calls the 1.x API stable but publishes no versioning policy. Dependabot skips client minors and majors, so the client only moves together with the image pins and the range.

1.0.0's breaking change refuses tag-scoped callers on whole-bank operations. Cogmo's callers are unscoped: the API-key tenant extension runs without an operation validator. 0.10.3 and 1.0.0 add no Postgres migrations. The recorded extraction and embedding fixtures replay unchanged, and the routes open without the API key are the same five.
