Chat turns send a stored system prompt snapshot (`system_prompt_snapshots`) that stays byte-identical for a conversation epoch, so a core-memory edit leaves the cached prefix intact: the change is announced once, with its content, in the next turn context. An epoch opens at a conversation's first turn, when the configuration digest changes (prompt text, rules, tools, the core-memory scope) or when a stored summary moves the history's start, and opening one strips earlier turns' thinking blocks. Every channel-scoped rule renders labelled with its channel, and the turn context names the delivery channels.
