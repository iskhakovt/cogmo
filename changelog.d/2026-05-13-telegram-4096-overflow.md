Fix Telegram MESSAGE_TOO_LONG errors when a streamed assistant reply exceeds Telegram's 4096-char per-message cap. The adapter now rotates to a new message before the cap, splitting at the highest-quality boundary available (paragraph > line > sentence > word > hard cut). Hard cuts back off one code unit if they would fall between halves of a surrogate pair, so astral-plane emoji never split. Each rotated chunk is finalized with HTML rendering; the next chunk starts a fresh message.
