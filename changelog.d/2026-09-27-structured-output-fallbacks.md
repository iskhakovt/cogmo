Structured output covers the schemas its constrained decoders can't. On Anthropic, a recursive schema takes the tool path, which carries the schema's definitions; a schema past the grammar's compile limits is re-sent once on the tool path; and an `enum` or `const` string that differs from a member only in capitalization takes the member's casing. On OpenAI-compatible providers, a schema outside strict mode's subset goes with `strict: false`, so pipeline compilation and the Observer's correction and memory extraction work against OpenAI.
