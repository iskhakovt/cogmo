Structured output handles schemas its constrained decoders reject. On Anthropic, a recursive schema or a tuple takes the tool path; a schema past the grammar's compile limits is re-sent once on the tool path; and an `enum` or `const` string that differs from a member only in capitalization takes the member's casing. Every Anthropic tool carries its schema's `$defs`, so MCP tools' `$ref`s resolve. On OpenAI-compatible providers, a schema outside strict mode's subset goes with `strict: false`, so pipeline compilation and the Observer's correction and memory extraction work against OpenAI.
