Bumped Inngest and Hindsight to their latest releases. Inngest: SDK `4.4.0 → 4.5.1` (no breaking changes) and the dev/test dev-server image `v1.19.2 → v1.27.0`. Hindsight: npm client `0.7.2 → 0.8.1`, the dev/test image pins (full + slim) `0.7.2 → 0.8.1`, and `cogmo.hindsightCompat` `>=0.7.0 <0.8.0 → >=0.8.0 <0.9.0`. The one breaking change in Hindsight 0.8 — removal of the `opinion`/`agent` fact types — doesn't affect Cogmo, which only recalls `world`/`experience`/`observation`. The compat gate stays anchored to the shipped client's minor (a fresh `>=0.8.0 <0.9.0` window each minor rather than a widened `>=0.7.0 <0.9.0`), so the client↔pin drift check keeps its teeth and a pre-1.0 minor bump forces re-validation at boot.
