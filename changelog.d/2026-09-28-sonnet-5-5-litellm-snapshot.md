**Claude Sonnet 5.5 is the default model and resolves its real limits.** `data/litellm-models.json` is refreshed from upstream LiteLLM (3,182 entries, 170 new, none dropped), so `claude-sonnet-5-5` resolves to a 1M context window and the 64k output budget cap instead of the 128k/4k fallback. No Claude entry changed, but 11 existing entries did. For example, `openrouter/qwen/qwen3-30b-a3b`'s output cap drops from 16,384 to 8,192, and `gemini-2.5-flash-native-audio-latest`'s context window drops from 1,048,576 to 131,072. `litellm-data.test.ts` pins both limits for each model in Anthropic's current lineup and for Sonnet 5, so a refresh that loses or shrinks one fails.

The Anthropic adapter needs no change for the model. It sends no `thinking` parameter, no sampling parameters and no forced `tool_choice`, which covers what Sonnet 5.5 rejects. Like Opus 5.5 and Fable 5.1, it binds thinking blocks to the prefix that produced them. Unlike Sonnet 5, it supports mid-conversation system messages and `clear_at`, and it caches from 512 tokens. `design/prompt-caching.md`, `design/providers.md` and `todo.md` now include it in those model lists.

A fresh install's default profile now starts on `claude-sonnet-5-5` (`DEFAULT_PROFILE_MODEL`). An existing install keeps its profiles' models. `/model` moves a profile to Sonnet 5.5 once a routing row exists (`cogmo model add claude-sonnet-5-5 --provider <name>`). Two behaviours change on the default path. Notes longer than a sentence or two between tool calls come back as `thinking` blocks, empty under the default `display`, so chat goes quiet between tool calls. On an Anthropic account created on or after 2026-08-31, the preserved-thinking check is enforced, so the history rewrites `todo.md` lists under that audit are 400s rather than latent.

The pipeline integration suites had inherited the default and still passed after the move, because aimock's model match also accepts the fixture's id followed by `-<digit>…` (meant for dated snapshots). A `claude-sonnet-5` cassette was answering `claude-sonnet-5-5` requests with another model's recording.

- Every loaded cassette fixture now matches its recorded model exactly or as a dated snapshot (`-YYYYMMDD`) only (`narrowModelMatch`).
- The miss description follows the same rule.
- The pipeline suites pin their profile to `CASSETTE_CHAT_MODEL`, like the other chat suites, through one helper that fails unless exactly one org profile changed.

The live tests that exercise "the production chat model" now follow `DEFAULT_PROFILE_MODEL`, and the per-model lists include Sonnet 5.5. The live evals stay on `claude-sonnet-5`, the model their documented baselines were measured on; `LIVE_MODEL` measures another. The preserved-thinking audit in `todo.md` moves to p1.
