New `/status` Telegram control command that surfaces the active conversation's state at a glance: alias, age and idle time, message count, active profile (name, model, tool count, auto-recall, memory scope), last LLM turn's persisted input/output tokens with model context budget and percent used, steering-rule count, and MCP fan-out (enabled servers, approved tools vs budget). Read-only — no LLM `countTokens` call, just the persisted `messages.input_tokens` from the last assistant row vs `getModelLimits(model)`. Backed by a new aggregate `Transport.conversations.summary()` that fans out the underlying store reads in parallel; agent store gains `getAliasForConversation` and `getConversationStats` (createdAt + count + lastMessageAt in one tx) to support it. `contextBudget` degrades to `null` when the active model is unregistered so a misconfigured profile can't break the status surface.
