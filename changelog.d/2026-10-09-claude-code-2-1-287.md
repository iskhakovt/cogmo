**The devbase image runs Claude Code 2.1.287**, its current `stable` dist-tag. The CLI's built-in skill list gains `plugin-authoring`, which changes the first user turn, so the `claude-cli` cassette is recorded from scratch. None of the stream-json events `claude.ts` parses change. What reaches coding tasks:

- Execute's `--resume` of the plan session no longer re-sends earlier messages in a changed form (which could drop the plan's reasoning), and a session that crashed after parallel tool calls no longer resumes with its turns lost.
- A revoked OAuth token fails a run with an error starting "Failed to authenticate" in place of a generic `API Error: 401`.
- A failing model call sends at most 14 requests across all retries.

2.1.285 starts `-p` sessions with telemetry off in auto mode when no permission mode is set; plan and execute both pass `--permission-mode`, so neither is affected.
