**The devbase image runs Claude Code 2.1.287**, its current `stable` dist-tag. The CLI's built-in skill list gains `plugin-authoring`, which changes the first user turn, so the `claude-cli` cassette is recorded from scratch. The shapes of the stream-json events `claude.ts` parses are unchanged. What reaches coding tasks:

- Execute's `--resume` of the plan session no longer re-sends earlier messages in a changed form (which could drop the plan's reasoning), and a session that crashed after parallel tool calls no longer resumes with its turns lost.
- During a non-streaming fallback request the CLI emits a `ping` every 30 seconds, which restarts the exec's 5-minute idle deadline, so only the 30-minute total cap bounds that request. The fallback's usage now reaches the `result` event, and with it `resource_usage`.
- A failing model call sends at most 14 requests across all retries.
