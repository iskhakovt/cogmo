`/repair` Telegram command — user-facing escape hatch over PR #136's status guard. New `Transport.conversations.repair(handle, conversationId)` flips `conversations.status` from `errored` back to `active`; identity + ownership checked like `setAlias`/`setProfile`; idempotent (`{wasErrored: false}` when already active, no DB write). New `handleRepair` in the Telegram adapter — `/repair` acts on the current session, `/repair <alias|uuid>` targets a specific conversation. 5 new Transport tests + 7 command-handler tests; 1996 unit tests pass total.
