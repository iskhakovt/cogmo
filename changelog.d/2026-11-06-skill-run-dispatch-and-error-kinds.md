Skill runs gain a `dispatched` recovery point, a failure kind and an audit trail (design/skills.md → Run failures, At-most-once invocation).

- Every runtime moves its run `started → dispatched` by conditional UPDATE immediately before it sends `task_invoke`, writing `deadline_at` (the wall clock plus 60 s). A task the pool, the worker or the populate stopped before that is recorded `started → executed` as a pausing error that says no skill code ran.
- `skill-runs-sweeper`, every 5 minutes, finishes a run left at `started` for 15 minutes as `host_lost` and one `dispatched` past its deadline as `result_lost`, and re-fires nothing. A task the sweeper beat is not sent, a late `transitionToExecuted` returns `swept` and logs the output it discards, and a keyed retry replays the sweeper's error instead of refusing the run as in flight forever.
- `skill_runs.error_kind` (`skill_run_error_kind`) is set with every `error`, so a recovered `executed` row finishes with the kind the worker reported. Each kind has a class (`defect`, `expected`, `pausing`, `lost`, `legacy`), and a tool run's failure reaches the model by it. An `output_invalid` verdict keeps what the skill returned.
- Both tiers' workers report the kind in `task_result.errorKind`: `load_failed` for a body that will not compile or import or has no `async def run`, `skill_raised`, `memory_exceeded` and `output_invalid`. A task sent whose worker then died or hung is `result_lost`, as a swept one is: its body may have acted. Both encode the return value with `json.dumps(..., allow_nan=False)` and refuse an integer past 2**53, so `NaN`, a `set` or an id the host would round fails in the worker. `SUPERVISOR_PROTOCOL_VERSION` is 4, so the container tier needs the `cogmo-skills` image of this release.
- `skill_runs` records the run's `git_sha`, run-as user and profile, and `shadow`. Migration `0082_skill_run_schema` adds them in one transaction with the enum value and the rewritten CHECKs, and backfills `error_kind = 'unknown'` on earlier error rows and `shadow = false` on every row.
