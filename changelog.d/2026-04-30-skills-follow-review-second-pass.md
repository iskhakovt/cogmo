Skills P3.3 follow-up review (PR #112, second pass) — six refinements + one type-system upgrade. (1) **FS-then-DB ordering reversed** in `executeRegister` / `executeApprove` / `executeRollback`: DB writes now run BEFORE `applyFilesystem`. Either path failure rolls back cleanly; the only remaining inconsistency window is "tx commit fails after FS succeeded" — the reverse ordering exposed every DB-write-after-FS-success failure as a half-deploy. (2) **No-op-after-denial fix**: `executeRegister`'s no-op guard now requires `existing.gitSha === branchTipSha && !existing.disabled`. Without `!disabled`, a denied-then-re-registered skill would return "no_op: nothing to deploy" while staying dark. (3) **Deny reason logged from runner**: `denyDeploy` info-logs `{pendingId, reason}` so the audit trail captures it without a schema column. (4) **`as unknown as JsonSchema` cast eliminated** via type-system fix — split `SkillIoSchema` into a stricter `SkillInputsSchema` (requires `type: "object"` literal at the manifest boundary, `passthrough` for extra JSON-Schema keys) used for `manifest.inputs` / `skills.inputs` / `SkillToolDef.inputs`, and the original `SkillIoSchema` retained for `outputs` (which can be any JSON Schema). `SkillInputs` is now structurally compatible with `JsonSchema`; `skill-tool-builder.ts` assigns it directly. Required tweaking `JsonSchema.properties` / `required` to `T | undefined` to round-trip Zod's `.optional()` output under `exactOptionalPropertyTypes: true` — runtime serialisation drops undefined either way. (5) **`outputsValidator` cache** moved onto the `SkillSourceCacheEntry` interface field (was attached via cast-and-mutate); same lazy-compile semantics, no rep exposure. (6) **Dead defensive checks dropped** in `executeApprove` (the `length === 0` + `!row[0]` pair after each select). (7) **`STUB_CLASSIFIER_LOG` localised** to `__registerForTests` since that was the only consumer. (8) **Pending-approval branch cleanup** carved into a `p3` todo — the schema needs an extra column on `skill_deploys` to preserve the original branch name; deferred until ref accumulation matters. New regression tests: deny→re-register reactivates instead of no_op; FS-callback-throws rolls back skills + skill_deploys (direct `executeRegister` test); inputs-not-object schema rejected at the manifest layer with `inputs.type` error path. 1792 unit + 88 integration tests pass.
