The system prompt's `# User` section renders the core memory blocks of the conversation's user, the same user `core_memory_update` writes for. `PromptSource.assemble` takes the conversation's `userId`, and every caller passes it: `handle-message`, pipeline stage turns and `/compact`. With more than one user (`mapped` or `create` identity modes), each user sees their own blocks rather than the first user's. A single-user install renders the same prompt as before. Unit tests pin the contract at `DefaultPromptSource`, which renders the requested user's blocks and not another user's, and at each of the three callers, which pass the conversation's user.
