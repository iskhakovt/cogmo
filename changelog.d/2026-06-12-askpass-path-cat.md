**Host-side git askpass helper works on non-FHS hosts (NixOS).** `withGitAskpass` wrote a helper script that exec'd `/bin/cat`, which doesn't exist outside FHS layouts — on NixOS every host-side authenticated git operation (WIP-preservation teardown pushes, repo-add clone, run-branch pushes) failed with `unable to read askpass response`. Both the host-side helper and the per-task container helper (`src/sandbox/askpass.ts`) now resolve `cat` via PATH — the host process env is trusted, and in the container PATH poisoning grants nothing the attacker doesn't already have. PATH resolution also keeps the container-shaped helper runnable when test fakes execute it on the host.
