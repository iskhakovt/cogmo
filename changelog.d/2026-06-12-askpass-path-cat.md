**Host-side git askpass helper works on non-FHS hosts (NixOS).** `withGitAskpass` wrote a helper script that exec'd `/bin/cat`, which doesn't exist outside FHS layouts — on NixOS every host-side authenticated git operation (WIP-preservation teardown pushes, repo-add clone, run-branch pushes) failed with `unable to read askpass response`. The helper now resolves `cat` via PATH; the host process env is trusted, so PATH resolution is safe. The in-container helper keeps its absolute path — task images are FHS and their PATH isn't ours to trust.
