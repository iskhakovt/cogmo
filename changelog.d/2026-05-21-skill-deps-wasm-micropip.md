Tier-1 (WASM / Pyodide) skills can now install declared Python dependencies. The Pyodide worker parses `requirements.lock` host-side, threads the resulting `name==version` specs into the worker's `workerData`, and runs `micropip.install(specs, keep_going=False)` before signalling `ready`. Pyodide-incompatible packages (anything without a Pyodide wheel and no pure-Python fallback on PyPI) surface as a `fatal` worker-init error, which the runner turns into the task's `error` — same UX shape as the sysbox tier's populate failures. Hashes are not enforced here because Pyodide / micropip don't have a `--require-hashes` equivalent; the staleness gate stays upstream at register (PR2's compile + byte-compare). `parseLockfilePackageSpecs` in `src/skills/deps.ts` is the single parser used by both tiers — accepts uv's `--generate-hashes` output, skips comments and hash continuations, preserves declared order.
